Four detuned harmonic waves, an elliptical decay and a 20-character density alphabet produce a reproducible texture. Not a badge, not a contribution counter, and not an image served from a tracking endpoint. The blank space is part of the score.

Run it locally:

```sh
node generate.mjs
node generate.mjs 1.5  # change the phase, change the composition
```

The program uses only built-in JavaScript math and writes ASCII to standard output. It has no dependencies, network access, randomness, telemetry or live data. Its output can be saved, printed, recombined, or piped into other terminal art.
